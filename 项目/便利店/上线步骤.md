# 亚伟便利店 — 上线步骤

## 第 1 步：推送到 GitHub

1. 按键盘 **Win + R**，输入 `cmd`，回车
2. 复制下面这行，在黑色窗口里右键粘贴，回车：

```
cd D:\claude_project\EIS_Nyquist_Toolkit && git push fuel-cell-eis-data-process main
```

3. 会弹出一个 GitHub 登录窗口 → 点绿色的 **Authorize** 按钮
4. 等待上传完成（约 10 秒）

---

## 第 2 步：部署到 Streamlit Cloud

1. 浏览器打开 https://share.streamlit.io
2. 点 **Sign in with GitHub** 登录
3. 点右上角 **New app**
4. 填写：
   - Repository: `AlexDai753/fuel-cell-EIS-data-process-tool-EIS-`
   - Branch: `main`
   - Main file path: `项目/便利店/app.py`
5. 点 **Deploy!** 按钮
6. 等待 2-5 分钟，部署完成后你会得到一个链接：
   `https://xxx.streamlit.app`

---

## 第 3 步：配置管理员密码

1. 在 Streamlit Cloud 找到你的 App
2. 点右上角 **Settings** → **Secrets**
3. 添加：
```
ADMIN_PASSWORD = "你的密码"
```
4. 点 Save，App 会自动重启

---

## ✅ 完成！

用手机 4G/5G 打开 `https://xxx.streamlit.app` 就能用了。
