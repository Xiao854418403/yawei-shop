# 小明便利店 — 部署说明

## 🚀 快速启动

### 本地运行

```bash
# 1. 安装依赖
cd 项目/便利店
pip install -r requirements.txt

# 2. 初始化商品数据（首次运行自动执行，也可手动运行）
python seed_data.py

# 3. 启动应用
streamlit run app.py --server.port 8504
```

浏览器打开 http://localhost:8504

### 管理员入口

1. 网页侧边栏选择「🔧 后台管理」
2. 输入密码：`admin123`（可在 `config.yaml` 修改）

---

## ☁️ Streamlit Cloud 部署

### 1. 推送到 GitHub

将整个项目推送到 GitHub 仓库。

### 2. 在 Streamlit Cloud 创建 App

1. 登录 https://share.streamlit.io
2. 点击「New app」
3. 选择仓库和分支
4. Main file path 填写：`项目/便利店/app.py`
5. 点击「Deploy」

### 3. 配置管理员密码（重要！）

在 Streamlit Cloud 的 App settings → Secrets 中添加：

```toml
ADMIN_PASSWORD = "你的强密码"
```

> `st.secrets` 的密码优先级高于 `config.yaml`，云端部署请务必修改默认密码。

## 📁 文件说明

| 文件 | 用途 |
|------|------|
| `app.py` | 主程序 |
| `data_manager.py` | 数据读写 + 并发安全 |
| `seed_data.py` | 初始化示例商品 |
| `config.yaml` | 店名、密码、品类配置 |
| `data/products.json` | 商品数据（自动生成） |
| `data/orders.json` | 订单数据（自动生成） |
| `requirements.txt` | Python 依赖 |

## 🔧 配置修改

编辑 `config.yaml`：

```yaml
store:
  name: "你的店名"          # 修改店名
  phone: "138-xxxx-xxxx"   # 修改电话
  delivery_note: "配送说明"

admin:
  password: "你的密码"       # 修改管理员密码

categories:                 # 增删品类
  - 零食
  - 饮料
  - ...
```

Streamlit 自动适配移动端。手机浏览器打开应用链接即可。

- 侧边栏在小屏自动折叠（左上角 `>` 展开）

---

## ⚠️ 注意事项

1. **数据持久化**：JSON 文件存储在 `data/` 目录，Streamlit Cloud 重新部署时会丢失。建议定期在后台导出数据。
2. **并发安全**：通过 `filelock` 文件锁保证库存不超卖。
3. **密码安全**：云端部署请用 `st.secrets` 管理密码，不要将密码写在 `config.yaml` 中提交到公开仓库。
4. **扩展建议**：如果订单量大，可迁移至 SQLite 或其他数据库。
